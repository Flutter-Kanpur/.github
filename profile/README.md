## 🏅 Contributor Recognition

Every merged PR, doc fix, bug report, or hour spent helping at an event moves this community forward — and we're building a badge system to make sure that work gets seen, not just remembered. Contributors are earning recognition for things like:

- **First Contribution** — landed your first merged PR
- **Pull Request** — ongoing code contributions
- **Documentation** — improving guides and docs
- **Bug Hunter** — reporting or fixing issues
- **Reviewer** — reviewing PRs and maintaining code quality
- **Event Support** — helping organize or run community events

Contributed to Flutter Kanpur in any way? Open an issue on this repo or reach out to a maintainer to claim yours.
